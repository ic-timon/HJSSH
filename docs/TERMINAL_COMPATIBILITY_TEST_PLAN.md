## 测试方法

### 标准测试流程
1. **启动测试**: 在终端中执行命令
2. **基本操作**: 执行常见操作
3. **视觉检查**: 确认显示正确（布局、颜色、对齐）
4. **交互测试**: 测试键盘输入响应
5. **退出检查**: 确认正常退出，屏幕状态恢复
6. **记录结果**: 记录通过/失败及问题描述

### 问题分类
- **A级（阻断）**: 完全无法使用，崩溃或显示混乱
- **B级（严重）**: 主要功能受限，但可勉强使用
- **C级（一般）**: 次要功能问题，不影响主要使用
- **D级（轻微）**: 细节问题，基本不影响使用
