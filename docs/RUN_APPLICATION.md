# 运行应用程序

## 运行终端应用

现在应用已经集成了终端 UI，运行后会显示一个模拟的 SSH 终端界面。

### 运行命令

```bash
# Windows
.\gradlew.bat :composeApp:run

# macOS/Linux
./gradlew :composeApp:run
```

### 当前功能

✅ **已实现：**
- 终端视图显示（黑色背景，白色前景）
- Mock SSH 连接（自动输出示例内容）
- ANSI 颜色支持（绿色、蓝色、黄色等）
- 光标闪烁动画
- 自动调整终端尺寸

✅ **文本渲染：**
- 已实现真正的文本渲染，使用 Skia 直接绘制文本
- 支持等宽字体（Courier New, Consolas, Lucida Console 等）
- 支持粗体文本
- 支持颜色和样式

### 预期显示

运行后，你应该看到：
1. 黑色背景的终端窗口
2. 几秒钟后开始显示文本内容：
   - "Welcome to Mock SSH Terminal!"
   - "This is a demonstration terminal."
   - 绿色的命令提示符：`user@host:~$`
   - 模拟的命令输出（ls, echo 等）
3. 闪烁的光标（每 500ms 闪烁一次）
4. 不同颜色的文本（绿色、蓝色、黄色）

### 如果看不到内容

如果窗口是空白的，可能的原因：
1. 终端缓冲区还没有内容（等待几秒钟）
2. 字符大小太小（当前是 8x16 像素）
3. 窗口大小问题
